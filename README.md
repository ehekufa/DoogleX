# DoogleX

Нативное Android-приложение для поиска и просмотра сайтов в одном месте. Интерфейс написан на Kotlin и Jetpack Compose. Результаты и выбранные страницы открываются внутри DoogleX, без автоматического перехода во внешний браузер.

## Скачать APK через GitHub Actions

1. Откройте [DoogleX Android APK](https://github.com/ehekufa/DoogleX/actions/workflows/android-apk.yml) во вкладке **Actions**.
2. Выберите последний успешный запуск нужной ветки. Для ручной сборки нажмите **Run workflow**.
3. Внизу страницы запуска скачайте **Artifacts → DoogleX-APK**.
4. Распакуйте ZIP и перенесите `DoogleX-debug.apk` на телефон.
5. Откройте APK на Android и разрешите установку из этого источника, если система попросит.

APK из workflow — установочная debug-сборка для тестирования. Артефакт хранится 14 дней. Для публикации релиза потребуется отдельный release-ключ, который не хранится в репозитории.

## Что умеет приложение

- поиск с нативным списком результатов DuckDuckGo;
- DNS over HTTPS для поиска через Cloudflare, Google или Quad9 без возврата к системному DNS при ошибке;
- HTTPS-only и доверие только системным сертификатам для сетевых запросов;
- безопасный поиск и локальная история, по умолчанию выключенная;
- сохранённые закладки и отдельная вкладка «Стиль» с сохраняемой кастомизацией;
- браузерные вкладки с отдельной историей переходов, закрытием и новой вкладкой;
- адресная строка для полного URL, домена вроде `github.com/…` или поискового запроса;
- открытие URL напрямую из поля на главной;
- классическое оформление с нейтральным фоном и синим акцентом;
- режим совместимости по умолчанию: ресурсы сайтов и сторонние cookies не фильтруются;
- приватная сессия по умолчанию: очистка cookies, кэша, form data и истории при закрытии;
- кнопка «Новая сессия» для очистки данных и сброса браузерных вкладок;
- опциональная строгая блокировка сторонних cookies и известных трекеров, запрет разрешений устройства;
- демонстрация и запись экрана без чёрного кадра;
- отдельная кнопка для открытия текущей страницы во внешнем браузере.

История, закладки и настройки хранятся локально через DataStore. У DoogleX нет собственного сервера. Поисковые запросы отправляются непосредственно в DuckDuckGo, поэтому при поиске применяется его политика конфиденциальности.

## Кастомизация

Вкладка **«Стиль»** объединяет новые параметры и существующий выбор темы, не дублируя его в общих настройках:

- классическое браузерное или фирменное оформление DoogleX;
- системная, светлая или тёмная тема приложения;
- шесть акцентных палитр для фирменного стиля: лайм, небо, коралл, фиолет, мята и графит;
- масштаб текста приложения 90–130%;
- включение подсказок на главной и компактный режим результатов/закладок;
- масштаб текста сайтов 80–200%;
- компьютерная раскладка и принудительное затемнение светлых страниц при поддержке WebView;
- отдельные переключатели изображений и JavaScript;
- скрытие панели приватной сессии;
- управление блокировкой известных трекеров, сторонними cookies и сохранением сессии;
- сброс только кастомизации без удаления закладок, истории и параметров поиска/DNS.

В общих настройках можно отдельно выбрать DoH-провайдера. Все варианты используют HTTPS и числовые bootstrap-адреса. При ошибке резолвера поиск завершается ошибкой, а не незаметно возвращается к обычному DNS.

Режим **«Совместимость сайтов»** включён по умолчанию и не фильтрует ресурсы страниц или сторонние cookies, чтобы GitHub и другие сложные сайты могли работать без лишних ограничений. Если режим выключить, становятся доступны строгие переключатели известных трекеров и сторонних cookies. HTTPS-only, системные сертификаты и запрет разрешений устройства остаются активными в обоих режимах.

Если включено сохранение сессии, cookies, кэш и сайтовое хранилище не удаляются при закрытии страницы. Кнопка «Новая сессия» всё равно выполняет явную полную очистку и сбрасывает вкладки. Состояние вкладок хранится только в памяти открытого браузера и не добавляется в локальную историю поиска.

## Приватность без готового Tor

Tor, Orbot и `tor-android` не используются. Содержимое поисковых запросов шифруется TLS. DNS нативного поиска отправляется через HTTPS выбранному провайдеру (Cloudflare, Google или Quad9) с bootstrap по числовым IP-адресам; при недоступности DoH приложение не переключается незаметно на DNS провайдера.

**Ограничения:** без Tor или собственного удалённого шлюза невозможно скрыть от провайдера IP-адрес назначения, домен из SNI и объём трафика. DoH относится к нативному поиску; WebView использует системный DNS. «Новая сессия» удаляет локальные данные, но не меняет IP-адрес. Системный WebView не воспроизводит антифингерпринт-защиту Tor Browser.

## Технологии

- Kotlin 2 + Jetpack Compose / Material 3;
- OkHttp + DNS over HTTPS — сетевые запросы и защищённый DNS поиска;
- Jsoup — преобразование выдачи в нативную модель;
- DataStore — локальные настройки и данные;
- Android System WebView (Chromium) — только для просмотра выбранных сайтов внутри приложения;
- GitHub Actions — unit-тесты и сборка APK.

Поисковый интерфейс не является браузерным фронтендом. Electron и отдельный браузер для открытия результатов по умолчанию не используются. Минимальная версия — Android 8.0 (API 26).

## Локальная сборка

Нужны JDK 17 и Android SDK 35:

```bash
./gradlew testDebugUnitTest assembleDebug
```

Готовый файл появится в `app/build/outputs/apk/debug/app-debug.apk`.
